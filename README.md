# ระบบบริหารจัดการของเสียสารเคมีและของเสียอันตราย

ระบบเว็บแอป (Single-page, ไฟล์เดียว `index.html`) สำหรับห้องปฏิบัติการ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏหมู่บ้านจอมบึง ใช้บันทึก ติดตาม และออกรายงานของเสียสารเคมี/ของเสียอันตรายตามแบบฟอร์มราชการ **FW-HZW-05** (รายเดือน) และ **FW-HZW-06** (รวบรวมไปกำจัด)

ไม่ต้องติดตั้งเซิร์ฟเวอร์หรือฐานข้อมูลใดๆ ทำงานได้ทันทีเมื่อเปิดไฟล์ `index.html` ในเบราว์เซอร์ ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น (รองรับการซิงก์ผ่านคลาวด์เพิ่มเติมได้จากหน้าตั้งค่า)

| ⚗️ เกณฑ์การคัดแยก | ข้อมูลเกณฑ์การจำแนกประเภทของเสียอันตราย |

| 🏭 คลังของเสียกลาง | จัดการของเสียที่ส่งเข้าคลังกลาง เลื่อนสถานะ (คัดแยก → รอส่งกำจัด → ส่งมอบแล้ว) และ **บันทึกข้อมูลการส่งกำจัด**: ผู้รับกำจัด, วันที่ส่งมอบ, เลขที่ Manifest, วันที่ได้รับเอกสารรับรอง พร้อมตารางประวัติการส่งกำจัดที่แก้ไขย้อนหลังได้ |

| 📑 รายงาน | ออกรายงานตามแบบฟอร์มราชการ FW-HZW-05 (รายเดือน) และ FW-HZW-06 (รวบรวมไปกำจัด) พร้อมพิมพ์ PDF ขนาด A4 |
| ⚙️ ตั้งค่า & ซิงก์ | ข้อมูลหน่วยงาน (ใช้ในหัวรายงาน) และการซิงก์ข้อมูลผ่านคลาวด์ |

## โครงสร้างข้อมูล (เก็บใน localStorage)

- `KEY_C` — รายการภาชนะของเสียทั้งหมด (registry ของภาชนะ, สถานะ, ตำแหน่งจัดเก็บ, ข้อมูลการส่งกำจัด ฯลฯ)
- `KEY_I` — ข้อมูลรายการ Insert/ประเภทของเสีย
- `KEY_S` — ข้อมูลหน่วยงาน/การตั้งค่า

> **หมายเหตุ:** ข้อมูลอยู่ในเบราว์เซอร์ของผู้ใช้แต่ละเครื่อง อย่าลืมสำรองหรือซิงก์ข้อมูลเป็นระยะ ตามที่แจ้งไว้ในแถบเมนูด้านซ้าย

## การใช้งาน

### แบบเปิดไฟล์ตรงๆ
ดาวน์โหลด/โคลน repo แล้วดับเบิลคลิกเปิด `index.html` ด้วยเบราว์เซอร์ (Chrome/Edge/Firefox แนะนำ)

### แบบโฮสต์ผ่าน GitHub Pages
1. Push โค้ดขึ้น repository นี้ (ไฟล์หลักชื่อ `index.html` อยู่ที่ root)
2. ไปที่ **Settings → Pages**
3. เลือก Source เป็น branch `main` โฟลเดอร์ `/ (root)` แล้วบันทึก
4. รอสักครู่จะได้ลิงก์ `https://<username>.github.io/<repo-name>/`

## เทคโนโลยีที่ใช้

- HTML + CSS + JavaScript (Vanilla, ไม่มี framework)
- ไลบรารีสแกน QR Code: [html5-qrcode](https://github.com/mebjas/html5-qrcode) (โหลดผ่าน CDN)
- Responsive / Mobile-friendly: มี breakpoint สำหรับหน้าจอมือถือ, ตารางเลื่อนแนวนอนได้, ฟอร์มจัดเรียงแนวตั้งอัตโนมัติ
- รองรับการพิมพ์รายงานเป็น PDF ขนาด A4 ผ่านฟังก์ชันพิมพ์ของเบราว์เซอร์

## การพัฒนาต่อ

โค้ดทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว (CSS และ JavaScript แบบ inline) แบ่งเป็นส่วนหลักๆ คือ:

- ส่วน `<style>` — ธีมสี, การจัดวาง, breakpoint สำหรับมือถือ
- สคริปต์ตัวช่วยลงทะเบียนของเสีย/ฉลาก/QR (ช่วงต้นของ `<script>`)
- สคริปต์หลักของระบบ (routing ระหว่างหน้าเมนู, การจัดการ localStorage, ฟังก์ชัน render แต่ละหน้า, event listener กลาง)

ก่อนแก้ไข แนะนำให้สำรองไฟล์เดิมไว้ก่อน เนื่องจากเป็นไฟล์เดียวขนาดใหญ่ที่รวมทุกอย่างไว้ด้วยกัน
